# Bank Fratern — Codex Design System Pack

Pacote completo para implementar a identidade Bank Fratern com Codex/agente de código.

## Conteúdo
- **8 logos SVG**
- **12 ícones da jornada**
- **16 ícones UI**
- **12 imagens/fotos autorais PNG 16:9**
- **10 criativos SVG 16:9**
- CSS: tokens, components, utilities, home e journey
- Documentação, prompts e exemplos HTML

## Comece por aqui
1. Abra `index.html`.
2. Leia `docs/design-system.html`.
3. Use `CODEX.md` como comando para o agente.
4. Use `examples/home-final.html` como home recomendada.
5. Use `examples/journey-integrated.html` para a jornada com ícones.

## CSS recomendado
```html
<link rel="stylesheet" href="assets/css/tokens.css">
<link rel="stylesheet" href="assets/css/components.css">
<link rel="stylesheet" href="assets/css/utilities.css">
<link rel="stylesheet" href="assets/css/home.css">

```
