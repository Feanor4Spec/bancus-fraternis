# Bancus Fraternis — Design System Pack

Pack técnico para aplicar a identidade Bancus Fraternis em HTML, jornada do consorciado, simulador, dashboards e apresentações.

## Conteúdo

- `index.html`: página inicial de demonstração.
- `docs/design-system.html`: documentação visual completa.
- `assets/css/tokens.css`: cores, tipografia, sombras, radius e espaçamentos.
- `assets/css/components.css`: header, hero, cards, botões, badges, stage cards e criativos.
- `assets/css/utilities.css`: classes auxiliares.
- `assets/logos/`: logos em SVG.
- `assets/icons/`: 12 ícones da jornada + sprite SVG.
- `assets/creatives/`: 4 criativos 16:9 em SVG.
- `examples/`: exemplos de implementação.

## Uso rápido

```html
<link rel="stylesheet" href="assets/css/tokens.css">
<link rel="stylesheet" href="assets/css/components.css">
<link rel="stylesheet" href="assets/css/utilities.css">

<img src="assets/logos/bank-fratern-portal.svg" alt="Bancus Fraternis" class="bf-brand__logo">
```
